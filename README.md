# mk-tdev Homebrew Tap

Homebrew distribution for [Nori](https://github.com/mk-tdev/nori), a native macOS dashboard for CPU, GPU, temperature, memory pressure, Docker, app workloads, and developer caches.

## Install Nori

```sh
brew install --cask mk-tdev/tap/nori
```

Nori currently supports Apple Silicon Macs running macOS 14 or newer.

Nori is distributed for free without Apple Developer ID notarization. If macOS blocks the first launch, try opening Nori once, then open **System Settings → Privacy & Security**, scroll to Security, choose **Open Anyway**, and confirm **Open**.

## Upgrade or uninstall

```sh
brew upgrade --cask nori
brew uninstall --cask nori
```
